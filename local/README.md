# local/

Files specific to this machine's setup; not part of the upstream project.

- `launchers/` – the real launcher scripts (the root `.cmd` files are shortcuts to these)
- `config/` – `training.json`, `watch.json`, and `presets/` for other experiments
- `notes/` – `MODLOG.md` (change log vs. upstream) and `LOCAL-SETUP.txt`
- `backups/` – save and mod backups taken before installing the AI mod
- `requirements-local-lock.txt` – pinned Python environment
